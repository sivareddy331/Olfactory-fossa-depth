# Olfactory FossaWeb

Project structure for Olfactory FossaWeb:

- `frontend/` - Frontend application code.
- `backend/` - Backend application code and APIs.
- `ai_model/` - AI/ML model scripts and configuration.
- `uploads/` - Directory for uploaded files.
- `reports/` - Generated reports and analytics.
- `database/` - Database migrations, schema, and backups.
